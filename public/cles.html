🔑 Clés des notifications

Cette page fabrique, sur votre appareil seulement, les trois valeurs à coller dans Cloudflare pour activer les notifications. Rien n'est envoyé nulle part. Ne les partagez avec personne (ni dans une conversation).

VAPID_PUBLICValeur publique (nom de la variable : VAPID_PUBLIC).
VAPID_PRIVATESecret. À coller comme « Secret » dans Cloudflare.
NOTIF_KEYSecret. Chiffre les identifiants au repos. Si vous la perdez, il faudra réactiver les notifications.

Dans Cloudflare : Workers & Pages → appli-bmvr-relais → Settings → Variables and Secrets → Add : type « Secret » pour les trois. Générez une seule fois : en générer de nouvelles invalide les abonnements existants.
